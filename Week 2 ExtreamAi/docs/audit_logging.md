Audit Trail Logging



The governance system records every AI action for tracking and compliance.



Logging Flow:



1\. Prompt Input

User sends a prompt to the AI agent.



2\. Agent Decision

Agent analyzes the prompt and assigns a risk level.



3\. Action Triggered

The agent performs an action.



4\. Governance Result

OPA policy decides if action is allowed or blocked.



5\. Audit Log

All information is stored in a log file for traceability.
